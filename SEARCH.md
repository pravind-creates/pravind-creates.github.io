# Getting Opsenta found on Google & Bing

Live site: https://pravind-creates.github.io/opsenta-website/
Sitemap: https://pravind-creates.github.io/opsenta-website/sitemap.xml

This is a github.io subdomain, so Google/Bing can index it. Indexing is not instant and ranking is not guaranteed.

## Google Search Console (5 minutes)
1. Go to search.google.com/search-console and sign in.
2. Add property > URL prefix > enter https://pravind-creates.github.io/opsenta-website/
3. Verify with the HTML tag method: copy the meta tag Google gives you and paste it where the placeholder comment sits in index.html `<head>`, commit & push, then click Verify. (Do not invent a code.)
4. Sitemaps > enter sitemap.xml > Submit.
5. URL Inspection > request indexing for the homepage. Repeat for platform/emissions pages if you like.

## Bing Webmaster Tools (3 minutes)
1. Go to bing.com/webmasters, sign in, add the same URL (you can import from Google Search Console).
2. Verify similarly, then Sitemaps > Submit https://pravind-creates.github.io/opsenta-website/sitemap.xml
